# Portal Monitoring Kelistrikan Pendidikan SUMKAL 2026
**PT PLN (Persero) — Divisi Operasi Distribusi (ODS) | Regional Sumatera & Kalimantan (10 UID)**

Portal 1 pintu untuk memantau 3 program kelistrikan pendidikan sekaligus:
1. **Sekolah Vokasi 2026**
2. **Sekolah Terpadu 2026**
3. **Sekolah Rakyat Tahap 3 Tahun 2026** (Opsi A: otomatis menarik sheet `Rekap Nyala` dan menyaring 10 UID SUMKAL)

## Cara Menjalankan di GitHub Pages
1. Buka `app.js` dan tempel ID Google Sheets **Sekolah Vokasi** dan **Sekolah Terpadu** (ID Google Sheets **Sekolah Rakyat** sudah terisi otomatis).
2. Pastikan ketiga Google Sheets sudah diatur aksesnya menjadi **Anyone with the link → Viewer**.
3. Unggah `index.html`, `app.js`, dan `README.md` ke repository GitHub Anda, lalu aktifkan **Settings → Pages → Branch `main`**.
